常见问题

如何下载离线语言包？

  1. 保持联网，选择原文与目标语言。
  2. 查看语言栏中的模型状态。
  3. 如果显示“联网后可下载语言包”，点“下载”。
  4. 完成后再断网测试。成功下载的语言可以继续离线使用。

语言栏显示不支持怎么办？

请先升级到最新 iOS，换用另一组系统支持的语言，并确认设备已安装对应语言包。iOS 模拟器通常不包含 Translation 模型，请使用真机验证。

语音或拍照没有反应

  • 在 iPhone“设置 → 清清随译”中检查麦克风、语音识别、相机和照片权限。
  • 在系统“键盘与听写”中下载当前语言的设备端听写模型。
  • 拍照时保持文字清晰、光线充足并尽量正对镜头。

录音会上传吗？

默认不会。App 默认强制使用设备端语音识别。只有用户在设置中主动开启“语音识别允许临时联网增强”，并且设备端模型不可用时，才可能使用 Apple 在线语音服务。

免费版与 Pro 有什么区别？

免费版可完成基础文字、语音和拍照翻译。Pro 一次买断，永久解锁不限长文、不限长语音、音频文件导入和双语稿导出，不是订阅，不会自动续费。

已购买但 Pro 没有解锁

  1. 确认设备和 App Store 登录的是购买时使用的 Apple ID。
  2. 保持联网，打开“升级”或设置中的 Pro 页面。
  3. 点击“恢复购买”。
  4. 仍无法恢复时，通过 GitHub Issues 提供购买时间和错误提示，不要发送 Apple ID 密码或支付信息。

隐私说明

文字、照片和录音默认在设备上处理。购买由 Apple StoreKit 完成，App 不读取银行卡号或 Apple ID 密码。
