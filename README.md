# 清清随译支持网站

将当前目录中的三个文件发布到公开 GitHub Pages 仓库：

- `index.html`
- `privacy.html`
- `styles.css`

目标仓库名：`qingqingsuiyi-support`

目标地址：

- 技术支持：`https://ktn4sgrtgc-gif.github.io/qingqingsuiyi-support/`
- 隐私政策：`https://ktn4sgrtgc-gif.github.io/qingqingsuiyi-support/privacy.html`

在仓库 Settings → Pages 中启用 GitHub Actions 或从分支部署。发布后必须用无痕窗口验证，不需要 GitHub 登录。
